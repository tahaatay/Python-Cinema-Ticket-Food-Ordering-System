# 🎬 Cinema Ticket & Food Ordering System

A beginner-level Python console application that simulates a cinema
ticket and food ordering system.

## Features

- 🎬 Cinema selection
- 🎟️ Ticket calculation
- 🎓 Student discounts
- 🍿 Food menu ordering
- 💰 Revenue tracking
- 👥 Customer count
- 📊 Daily sales statistics
- 🎨 Colored console interface with Colorama

## Technologies

- Python
- Colorama

## Purpose

This project was created as a practice project while learning Python.
It focuses on functions, loops, conditionals, global variables,
input validation and basic program flow.
